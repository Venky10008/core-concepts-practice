# Task 2 - Core Frontend Concepts Practice

Six small practice exercises, one per concept, for Task 2 of my frontend internship. Plain HTML, CSS and JavaScript, no build tools.

Open `index.html` in a browser and click through the exercises. Exercise 5 prints to the console (press F12).

- ex1 - DOM manipulation
- ex2 - events (click counter and a small todo list)
- ex3 - form validation
- ex4 - flexbox vs grid
- ex5 - JavaScript basics, output in the console
- ex6 - responsive two-column layout
